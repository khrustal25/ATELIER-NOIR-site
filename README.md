# ATELIER-NOIR-site

Персональный лендинг-портфолио вайбкодера.

Концептуальный одностраничный сайт (с отдельными страницами инструментов) премиальной студии дизайна интерьеров **ATELIER NOIR**. Студия, проекты, тарифы и цены вымышлены; изображения — демонстрационные визуализации. Проект готовят к загрузке в репозиторий GitHub: сборка не нужна, сайт пока не считается опубликованным.

Сайт полностью статический: HTML, CSS и чистый JavaScript. Нет npm, сборщиков, фреймворков и серверной части. Страницы можно открыть двойным кликом по HTML-файлу.

## Разделы сайта

### Главная (`index.html`)

| Раздел | Что внутри |
| --- | --- |
| Hero | Крупный заголовок, краткий текст, переход к инструментам |
| Студия | Текст о подходе и фото студии |
| Проекты | Три концептуальные визуализации с названиями и стилями |
| Инструменты | Ссылки на квиз, конфигуратор и калькулятор |
| Подход | Четыре шага: исследование → персонализация → расчёт → доработка |
| Финальный блок | Призыв вернуться к инструментам |
| Контакт (подвал) | Навигация и юридическая пометка, что проект демонстрационный |

Отдельной формы заявки, телефона и реальных контактов на сайте нет.

### Отдельные страницы

- **Квиз стиля** (`quiz.html`) — шесть вопросов с фотографиями, результат со стилем, палитрой и материалами.
- **Конфигуратор** (`configurator.html`) — SVG-гостиная: стены, пол, диван, свет, декор.
- **Калькулятор** (`calculator.html`) — предварительная оценка стоимости дизайн-проекта в рублях.

Общее для всех страниц: переключатель русского и английского, адаптивная вёрстка, сохранение части настроек в `localStorage` браузера.

## Технологии

| Слой | Что используется |
| --- | --- |
| Разметка | HTML5, семантические секции, атрибуты `data-i18n` |
| Стили | CSS с переменными, без препроцессоров: `style.css` + `responsive.css` |
| Логика | JavaScript без библиотек и npm; отдельный файл на модуль |
| Шрифты | Cormorant Garamond и Manrope — локальные `.woff2` (латиница и кириллица) |
| Изображения | WebP на страницах; JPEG в `assets/images/og/` для превью Open Graph |
| Конфигуратор | Встроенный SVG, слои через `data`-атрибуты и CSS |
| Хранилище | Только `localStorage` в браузере пользователя |

Цвета дизайн-системы: фон `#F7F5F0`, текст `#292824`, второстепенный текст `#5E584F`, акцент `#8B7665`, линии `#C8BDB0`.

## Как запустить локально

Ничего устанавливать не нужно: нет `package.json` и зависимостей.

**Способ 1 — самый простой.** Откройте проводник, зайдите в папку проекта и дважды щёлкните по `index.html`. Сайт откроется в браузере. Все пути относительные, поэтому так можно смотреть и остальные HTML-страницы.

**Способ 2 — через локальный сервер** (ближе к обычному хостингу). В терминале:

```bash
cd "C:\Users\Zahva\Desktop\Проекты Cursora\ATELIER-NOIR-site"
python -m http.server 8000
```

Затем откройте в браузере адрес `http://localhost:8000`.

Подойдёт и любой другой статический сервер, например расширение Live Server в VS Code / Cursor.

**Важно:** у протоколов `file://` и `http://localhost` разный `localStorage`. Ответы квиза и сохранённые настройки между этими способами не переносятся.

## Что можно персонализировать

Меняйте только то, что хотите показать как своё. Ниже — реальные места в проекте (секретов и `.env` в репозитории нет).

| Что менять | Где |
| --- | --- |
| Тексты на русском и английском | `js/translations.js` (оба словаря с одинаковыми ключами) и дублирующий русский текст в HTML |
| Заголовки и блоки главной | `index.html` |
| Названия и описания проектов | ключи `project.01`…`project.03` в `translations.js` + картинки `project-01.webp`…`project-03.webp` |
| Фото и превью | файлы в `assets/images/` (сохраняйте имена или обновите пути в HTML/JS) |
| Иконку сайта | `assets/icons/favicon.svg`, `apple-touch-icon.png` |
| Цвета и отступы | CSS-переменные в начале `css/style.css` |
| Тарифы калькулятора | ставки и коэффициенты в `js/calculator.js` |
| Вопросы и баллы квиза | массив вопросов в `js/quiz.js` |
| Варианты конфигуратора | разметку и логику в `configurator.html` / `js/configurator.js` |
| Картинки для шаринга | `assets/images/og/*.jpg` и теги `og:image` в HTML |

Не переводятся только название бренда «Atelier Noir», переключатель RU/EN и технические символы.

Чтобы добавить новую строку перевода: создайте ключ в обоих словарях `translations.js` и укажите его в атрибуте `data-i18n` (или родственных `data-i18n-*`). В скриптах используйте `t("ключ")`.

## Квиз стиля

Шесть вопросов по четыре варианта с фотографиями:

1. Какая атмосфера вам ближе?
2. Какие цвета вам нравятся?
3. Какие материалы вы предпочитаете?
4. Какое пространство вы хотите создать?
5. Что для вас важнее всего?
6. Какой образ жизни вам ближе?

Каждый вариант начисляет баллы одному или двум стилям (от 1 до 3). Побеждает стиль с наибольшей суммой; при равенстве — тот, что раньше в списке:

1. Тёплый минимализм (`warm-minimalism`)
2. Джапанди (`japandi`)
3. Современная роскошь (`contemporary-luxury`)
4. Современная классика (`modern-classic`)

Результат показывает название стиля, описание, фотографию, палитру из четырёх цветов и материалы. Без выбора ответа дальше не пройти. Ответы и шаг сохраняются после каждого действия; «Пройти ещё раз» очищает сохранённые данные. Найденный стиль передаётся в конфигуратор как стартовая конфигурация.

## Конфигуратор пространства

Сцена гостиной нарисована в SVG. Пять групп настроек, по три варианта в каждой:

| Группа | Варианты |
| --- | --- |
| Стены | Слоновая кость, Песок, Графит |
| Пол | Светлый дуб, Орех, Натуральный камень |
| Диван | Крем, Карамель, Серый |
| Свет | Мягкий рассеянный, Архитектурный, Декоративный |
| Декор | Минимальный, Современный, Художественный |

- Стартовая конфигурация зависит от результата квиза; без квиза — набор «Тёплый минимализм».
- Текущий выбор сохраняется автоматически.
- «Сохранить» / «Восстановить» / «Сбросить» работают с отдельной сохранённой копией и стартовым набором.

## Калькулятор стоимости

| Параметр | Значения |
| --- | --- |
| Тип объекта | Квартира (×1), Дом (×1,15) |
| Площадь | 20–500 м² |
| Пакет | Базовый — 3 500 ₽/м², Авторский — 5 500 ₽/м², Индивидуальный — 8 000 ₽/м² |
| 3D-визуализация | 1 200 ₽/м² |
| Авторский надзор | 1 500 ₽/м² |
| Подбор мебели | 65 000 ₽ фиксированно |

```text
база       = площадь × ставка пакета × коэффициент объекта
доп. услуги = площадь × 1 200 (визуализация)
            + площадь × 1 500 (надзор)
            + 65 000          (подбор мебели)
итого      = база + выбранные доп. услуги
```

Коэффициент объекта применяется только к базе. Хранятся параметры, а не суммы — итог всегда пересчитывается. Тарифы демонстрационные и не являются офертой.

## Языки и localStorage

Язык (`atelier-noir-language`) и состояния инструментов хранятся только в браузере:

| Ключ | Содержимое |
| --- | --- |
| `atelier-noir-language` | `ru` или `en` |
| `atelier-noir-quiz` | ответы, шаг, найденный стиль |
| `atelier-noir-config` | текущая конфигурация |
| `atelier-noir-config-saved` | сохранённая конфигурация |
| `atelier-noir-calculator` | текущие параметры калькулятора |
| `atelier-noir-calculator-saved` | сохранённые параметры |

Если хранилище недоступно, сайт всё равно открывается, но без запоминания. Сброс: DevTools → **Application → Local Storage**.

## Подготовка к размещению в репозитории

Сборка не нужна: в репозиторий кладут содержимое этой папки как есть, чтобы `index.html` оказался в корне.

Файл `.nojekyll` уже добавлен на случай будущей выкладки через GitHub Pages. Относительные пути рассчитаны и на работу из подпапки репозитория.

Когда появится постоянный адрес сайта, для превью в соцсетях имеет смысл заменить в четырёх HTML относительные `og:image` на полные URL (сейчас стоят пути вида `assets/images/og/...`). Без этого сайт работает, но часть соцсетей может не показать картинку превью.

## Известные ограничения

- Сайт пока готовят к загрузке в репозиторий; готовой «живой» публикации в этом README нет.
- Поисковики и соцсети видят русские мета-данные: английская версия включается скриптом и не имеет отдельных URL.
- Данные в `localStorage` привязаны к браузеру и устройству и не синхронизируются.
- Отдельной страницы 404 в проекте нет.
